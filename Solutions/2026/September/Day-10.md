## Problem #47
Two Sum: Find two numbers in array that add up to target

## Solution
```python
class Solution:
    def twoSum(self, nums, target):
        """
        Find two numbers in array that add up to target
        
        Approach: Using HashMap for O(n) solution
        Time Complexity: O(n)
        Space Complexity: O(n)
        """
        # Create a dictionary to store value -> index mapping
        num_map = {}
        
        # Iterate through the array
        for i, num in enumerate(nums):
            # Calculate the complement needed
            complement = target - num
            
            # Check if complement exists in map
            if complement in num_map:
                return [num_map[complement], i]
            
            # Store current number and its index
            num_map[num] = i
        
        # Return empty if no solution found
        return []
```
