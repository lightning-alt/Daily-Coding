## Problem #52
Reverse String: Reverse a string in-place

## Solution
```python
class Solution:
    def reverseString(self, s):
        """
        Reverse a string in-place using two-pointer approach
        
        Approach: Two pointers from both ends
        Time Complexity: O(n)
        Space Complexity: O(1) - in-place reversal
        """
        # Convert string to list for in-place modification
        chars = list(s)
        left, right = 0, len(chars) - 1
        
        # Swap characters from both ends moving towards center
        while left < right:
            chars[left], chars[right] = chars[right], chars[left]
            left += 1
            right -= 1
        
        # Convert list back to string
        return ''.join(chars)

# Alternative: Using Python slicing (cleaner but not in-place)
class SolutionSlice:
    def reverseString(self, s):
        """
        Reverse string using Python slicing
        Time Complexity: O(n)
        Space Complexity: O(n) - new string created
        """
        return s[::-1]
```
